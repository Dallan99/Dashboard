# 📊 Dashboard Interativo em Excel - Projeto de Estudo

Este repositório contém um projeto de estudo focado na criação de um **dashboard interativo** utilizando o Microsoft Excel. O objetivo é praticar habilidades em análise e visualização de dados, além de aplicar boas práticas na organização de planilhas e na criação de relatórios visuais.

## 🧠 Objetivo

Desenvolver e aprimorar habilidades nas seguintes áreas:

- Manipulação e estruturação de dados no Excel
- Criação de dashboards com Tabelas Dinâmicas e Segmentações
- Visualização de métricas com gráficos interativos
- Separação lógica entre base de dados e visualização

## 📁 Estrutura dos Arquivos

- `data_base.xlsx`: Planilha com os dados brutos utilizados na análise.
- `dashboard.xlsx`: Planilha com o dashboard final montado, conectada à base de dados.

## 🛠️ Ferramentas e Recursos Utilizados

- Microsoft Excel
  - Tabelas e Tabelas Dinâmicas
  - Gráficos interativos
  - Segmentações e filtros visuais
- Conceitos de análise exploratória de dados

## 📌 Principais Funcionalidades do Dashboard

- Filtros interativos por categoria, período e outros parâmetros
- Indicadores visuais de desempenho
- Layout limpo e objetivo, com foco na interpretação rápida dos dados

## 🚀 Próximos Passos
